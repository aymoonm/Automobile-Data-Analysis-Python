# 🚗 Automobile Data Analysis (Cars Dataset)

## 📌 Project Overview
This project focuses on exploring and cleaning a comprehensive cars dataset using **Python** and **Pandas**. The goal is to derive insights about vehicle specifications, performance metrics, and manufacturing origins.

## 🛠️ Key Tasks Performed
- **Data Cleaning:** Identified missing values and handled them using mean imputation (`fillna`) to maintain dataset consistency.
- **Statistical Analysis:** Analyzed frequency of car brands and types using `value_counts`.
- **Advanced Filtering:** Segregated data based on specific origins (Asia, Europe) and performance criteria (Horsepower, MPG).
- **Data Modification:** Applied arithmetic operations to columns to simulate real-world data adjustments and transformations.

## 🧰 Technologies Used
- **Python** (Core Language)
- **Pandas** (Data Manipulation)
- **Jupyter Notebook** (Environment)

## 📊 Sample Insights
- Determined the average weight and wheelbase for various car categories.
- Filtered high-performance vehicles based on horsepower thresholds.
- Identified the most common car manufacturers within the dataset.
